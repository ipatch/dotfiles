## ubuntu / live system

i had issues installing **mpv** on my ubuntu 21.04 live ISO FWR.

to get mpv installed on ubuntu 21.04

```
sudo add-apt-repository universe multiverse
sudo apt update
sudo apt install mpv
sudo apt install intel-gpu-tools
```
